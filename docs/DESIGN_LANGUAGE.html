Exhale Design language · v1 · late July 2026

Sensory relief, rendered.

Exhale is a shared brain for the household — and its visual identity has one job: lower the reader's heart rate while telling them the truth. Every choice below serves that. This document is set in the system it describes; view it in light and dark (it follows your OS) and share it as-is. All values are the shipped app's actual tokens, not aspirations.

The emotional foundation

The product is named for the second half of a breath. The inhale is the world demanding things of a family; Exhale is the release — what's handled, what can wait, who has it covered. The identity projects three things, in order:

  • Sensory relief. Muted colors, generous whitespace, soft elevation, slow motion. The app should feel like exhaling — never like a dashboard, never like a to-do app's guilt engine.
  • Emotional de-escalation. Urgency is communicated without alarm. There is no red anywhere in the product: attention is a warm amber, and severity is a quiet dot with a halo — not a siren, not a badge shouting a number.
  • Data reliability. Calm must never read as vague. Numbers are set in tabular figures, provenance is cited, and the honest states — "a quiet week," "still listening," "nothing asserted yet" — are designed states, not empty ones.

Palette — 60 / 20 / 10 / 10

Four named colors, balanced so the page is mostly ground and text with sage as the working accent and amber reserved for attention. No pure red, no pure black, no saturated success-green. Every hex lives behind a CSS token, so the entire app flips light ↔ dark by swapping token values — no component knows a hex.

Typography — three voices

Three faces, three jobs, never mixed roles. The pairing is the personality: an editorial italic serif that makes headlines feel like a person speaking, over precise sans-serif workhorses that make the data feel dependable.

Display · Instrument Serif italic A lighter week. Breathe out.
Interface · Inter Tight 600 Review & Sign Draft →   (−0.02em tracking)
Labels · Inter Tight 700 caps What the family carried
Micro · Plus Jakarta Sans Body copy, data rows, captions — humanist and clean down to 12px. Numbers in columns get tabular-nums.

Conventions: display is always italic, never bold — headlines are spoken, not shouted. Section labels are uppercase with wide tracking (.13–.17em) in sage or muted ink. Interface text tightens (−0.02em); micro text never fakes smallcaps. Loaded from Google Fonts (Instrument Serif ital · Inter Tight 400–700 · Plus Jakarta Sans 400–600) with serif/system fallbacks.

Motion — everything breathes, nothing bounces

The breath orb — the thesis, made literal

A soft sage radial glow behind the header, scaling 1 → 1.14 over a 7-second ease-in-out cycle — the cadence of a calm human breath. It is the app's only ambient animation.

@keyframes exhale-breathe {
  0%, 100% { transform: scale(1);    opacity: .75; }
  50%      { transform: scale(1.14); opacity: 1;   }
}
.breath-orb { animation: exhale-breathe 7s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) {
  .breath-orb { animation: none; }
}
Motion rules
  • One ambient motion per screen — the orb. Everything else moves only in response to the user.
  • Transitions are fades and tint-shifts, 150–200ms ease. No slides, no bounces, no springs, no confetti — ever. Celebration is warm words, not particles.
  • Hover states deepen a tint (sage 10% → 20%) or warm a border; they never grow, lift, or glow elements.
  • Reduced motion is honored — the orb stills, nothing else needs to change because nothing else was moving.

Component vocabulary

Severity — the dot-and-halo, never a siren
Needs you — deadlines, hard weeks, dying threads
Safe / covered / verified / success
Advisory — worth knowing, not worth worrying

7px dot, 4px halo at 12–16% tint. Severity is stated once, quietly, next to the section title — never as a count badge, never blinking.

Buttons — three weights of ask

All fully rounded. Filled navy (--ink-solid) for the one primary act on a screen; sage-tint outline for affirmative actions; quiet outline for everything reversible. Labels say exactly what happens.

Cards & chips

Surfaces are white (navy in dark), 16–22px radius, 1px ink-10% border, and a low soft shadow (0 12px 24px rgba(26,43,76,.04)) — elevation you feel rather than see. Chips label state in the family's language:

Checked off  Ali's got it  Weekly  Together
Inputs

Fully rounded, canvas-tinted fill, ink-15% border warming to sage on focus. Placeholders are invitations ("The house needs…"), not formats ("Enter task name").

Voice — the copy is part of the design

Exhale says

  • "A lighter week. Breathe out."
  • "Needs you · 2" — then everything else is handled or watched
  • "Saturday morning looks open — got a little time?"
  • "Everything's covered this week. Nicely done."
  • "Last week was a hard one. That's not a failure, it's a week."
  • "Contributions" — the family's own word for chores
  • "Take a deep breath — your memory systems are secure."

Exhale never says

  • "⚠️ URGENT: 7 tasks overdue!" — no alarm voice, no count badges
  • "🎉 Great job!!" on a bad week — no confetti, no false cheer
  • "Ali: 7, Andy: 3" — no scores, totals, or rankings, anywhere
  • "You haven't…" — no guilt framing; absence is never displayed
  • "Streak: 12 days 🔥" — no gamification mechanics at all
  • Jargon — "sync failed (E401)" becomes "Google needs reconnecting"

The tenor rule: the interface always tells the truth at the temperature the truth deserves. A quiet week reads as calm only when nothing urgent is open; a behind week must never wear a party hat; cold-start states say "still listening," never fake fullness.

Emotional design rails — structural, not stylistic

These are product-level commitments the visual layer must uphold. They are enforced in the data (the payloads contain nothing that could violate them), and any new surface is held to the same bar.

  • Names, never numbers. Who-did-what is shown as prose with names — never counts, totals, percentages, or side-by-side comparisons.
  • No zero sections. A person with a quiet week is absent, never an empty column with their name on it.
  • Gratitude points outward. The thanks ♡ appears only on a partner's work.
  • Letting go is a release, not a win. Deleting or dropping is never celebrated, logged, or counted.
  • Suggestion, never nag. Time and tasks are laid side by side as an invitation; nothing is auto-scheduled into a person's day.
  • Attention without alarm. The worst news in the product is rendered in warm amber prose with a quiet dot — and it still leads with what to do next.
  • Honest instruments. Metrics never flatter: no score is shown before something real is measured, and corrected facts visibly lower what they touched.

The tokens — copy-paste foundation

The complete CSS custom-property set, exactly as shipped. Components reference tokens only (e.g. rgb(var(--sage) / 0.16)); an explicit user toggle sets data-theme on the root and must win over the OS preference in both directions.

:root {                       /* LIGHT */
  --ink: 26 43 76;            /* Sanctuary Navy — text, borders */
  --canvas: 244 246 249;      /* Pure Breath — page ground */
  --surface: 255 255 255;     /* cards / panels */
  --sage: 124 157 150;        /* Sage Release — safe, shared, success */
  --amber: 226 149 120;       /* Looming Amber — attention, not alarm */
  --ink-solid: 26 43 76;      /* filled primary button */
}
@media (prefers-color-scheme: dark) { :root {
  --ink: 226 232 240; --canvas: 12 20 32; --surface: 22 35 59;
  --sage: 166 195 188; --amber: 237 171 144; --ink-solid: 42 62 100;
} }
/* data-theme (user toggle) repeats both sets and wins over the media query */

body {
  font-family: "Plus Jakarta Sans", system-ui, sans-serif;
  background-color: rgb(var(--canvas));
  background-image:  /* the faint dawn */
    radial-gradient(120% 70% at 12% -5%, rgb(var(--sage) / .12), transparent 55%),
    radial-gradient(110% 70% at 100% 4%, rgb(var(--amber) / .10), transparent 50%);
  color: rgb(var(--ink));
}

/* Shape & elevation */
--radius-card: 16–22px;  --radius-control: 9999px (fully rounded);
--shadow-card: 0 12px 24px rgba(26,43,76,.04);
--border-hairline: 1px solid rgb(var(--ink) / .10);

/* Type roles */
--display:   "Instrument Serif", ui-serif, Georgia, serif;   /* italic, never bold */
--interface: "Inter Tight", system-ui, sans-serif;           /* -0.02em; labels 700 caps +.14em */
--micro:     "Plus Jakarta Sans", system-ui, sans-serif;     /* body & data; tabular-nums */
